Sort Employees by Name

Create an Employee POJO with: id, name

Use Comparator to sort employees by name alphabetically.

Input
Employee(101, "Ravi") -> Employee(102, "Amit") -> Employee(103, "Neha") -> Employee(104, "Kiran")

Expected Output
102 Amit -> 104 Kiran -> 103 Neha ->101 Ravi

Requirement: Do not implement Comparable. Use a Comparator<Employee> for sorting.
